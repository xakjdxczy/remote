本机连接 · Wi‑Fi 或 USB 二选一 · 不经过公网
配对码（手机上填写）
------
电脑局域网 IP

手机扫码，或打开尘埃 →「作为摄像头」，填 IP 和配对码。同一 Wi‑Fi 或一方开热点即可。

USB 线本身不是网络。adb 先打开手机「USB 调试」（荣耀/华为还要开「仅充电模式下允许 ADB」），再点「准备 USB」：电脑会自动转发并打开手机 App，不用手填地址和配对码。不想开调试：用 USB 网络共享，填电脑在那条 USB 网上的 IP。

预览（会议软件请再开虚拟设备）

点输出后，OBS / 会议软件选「尘埃 摄像头」和「尘埃 麦克风」。第一次会要管理员密码，把这两个虚拟设备装进系统。
